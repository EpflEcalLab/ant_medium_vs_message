
## Software requirements

The project files were developed and tested with TouchDesigner 2023.11760.

The files can be opened with TouchDesigner Non-Commercial for non-commercial use.

However, TouchDesigner Non-Commercial limits image resolution to 1280 × 1280 pixels.

Higher-resolution rendering or export requires an appropriate paid TouchDesigner license.

## External image material

Some visual stimuli use affective images from the International Affective Picture System (IAPS).

The IAPS images are not redistributed in this repository.

Users who wish to reproduce these stimuli must obtain access to the IAPS material through the appropriate source and licensing conditions.
